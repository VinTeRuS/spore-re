# spore-re

Русский | [English](README.md)

Нативный порт Spore (вместе с «Космическими приключениями») на Android. Это не эмулятор и не Wine: `SporeApp.exe`
статически перекомпилирован из x86 в C, собран под arm64 и работает поверх моей собственной прослойки Win32/D3D9
(SDL2, DXVK).

> **Проект на очень ранней стадии.** Коммиты будут частые и мелкие: быстрые фиксы, что-то будет ломаться и
> переписываться. Пока ничего стабильного нет, релизов тоже нет.

Если нравится порт, можно поддержать на Patreon: **[patreon.com/VinTeRuS](https://www.patreon.com/cw/VinTeRuS/membership)**.

## Что в репозитории

Только мой код: хост Win32/D3D9, Android-приложение (Java, сенсорное управление, настройки), скрипты сборки и
рекомпилятор (`third_party/x86recomp`). **APK, файлов игры и перекомпилированного кода игры здесь нет** и не будет.
Перекомпилированный код генерируется при сборке из вашей собственной копии игры.

## Состояние

- Работает на Pixel 6 (Mali-G78): меню, звук, галактика, стадия клетки, редакторы, остальные стадии через консоль читов.
- Управление: тап/перетаскивание = левая кнопка мыши, долгое нажатие = правая, два пальца = камера, щипок = зум,
  стик WASD.
- 20-60 fps в игре, загрузка стадий медленная. Над производительностью ещё работаю.
- Известные проблемы: нет поддержки C++ исключений (если игра кидает исключение, она падает), только процессоры
  ARMv8.2+, проверено на одном телефоне.

## Версия игры

GOG Spore Collection 3.1.0.22, `SporebinEP1/SporeApp.exe` (sha256 в `re/target.sha256`). Другие сборки не подойдут.

## Сборка (примерно)

Linux, Python 3, Android NDK, установленная игра.

1. `python3 -I third_party/x86recomp/tools/recomp.py ...` с `tools/recomp/game.py` генерирует C в `build/`.
2. `make -j3` в `src/native` для десктопной сборки (Linux), `make -j2 PLATFORM=android` для arm64.
3. `android/build-deps.sh`, затем `android/build-apk.sh` дают `build/apk/spore.apk`.

Инструкция станет подробнее, когда всё устаканится.

## Правовое

Нужна своя купленная копия Spore. Не просите файлы игры или APK. Spore является торговой маркой Electronic Arts,
проект не связан с EA и Maxis.
